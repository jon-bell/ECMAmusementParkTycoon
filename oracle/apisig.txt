# API signatures for the API trace (RCTHOOK_SPIKE=apitrace). Hand-written from the Win32/DirectX
# headers; no game data. Read by oracle/apitrace.c (embedded at build time), by tools/apitrace.py
# (canonicalisation, decoding) and by the JS host (to emit the same trace). Grammar and rendering
# rules: oracle/README.md, "API trace".
#
#   fn     <name> <conv> <ret> <arg>...        a function the game calls (import, GetProcAddress
#                                              result, or COM method "Iface::Method", this = arg 1)
#   iface  <Iface> <method>...                 COM vtable order
#   cb     <kind> <ret> <arg>...               a game callback the OS calls (B/E records)
#   struct <NAME> <field>...                   sequential layout, no implicit padding
#   msg    <msgno> <dir> <lparam kind>         window/dialog message lparam content (kind msgl)
#
# conv: std | cdecl.   ret: v x h p s ews eas a@L.
# arg:  [o|io] base [cond].  cond (out/io args only): ? (return != 0), ?0 (return == 0),
#                            ?-1 (return != 0xffffffff); when false the content is not rendered.
#                            base: x h p s ws g cb:K S:T I:I lpal bmi@N msgl s@L ws@L b@L x@L
#                            dx dh dp da@L
# struct fields: x1 x2 x4 h4 p4 s4 cN (char[N]: bytes after the first NUL render as "..")
#                bN (bytes[N]) uN (N unused bytes, e.g. padding: always "..")
